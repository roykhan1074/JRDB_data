# 新馬指数 仕様書

- 2026-10-13 作成。
- 表示場所: 出馬表（entries.html）列#10「新馬」。**新馬戦（T_BAC.class='A1'、芝ダ）のときだけ表示**。列#10は障害戦では「障害」（障害指数）、それ以外のレースでは幅0で非表示。

## 1. 目的

新馬戦は過去の成績が無く、平地の他のレースとも障害戦とも傾向が違う（調教の評価が市場に十分織り込まれていない、調教量評価Aは逆にマイナス等）ため、新馬戦専用の点数で評価する。過去成績の代わりに、父・厩舎・騎手・生産者・馬主の「その日より前の新馬戦の成績」を使う。

## 2. 要素と点数（29要素、固定ルール）

`python/research/newbie_wf.py` の walk-forward で2026年時点に選ばれた要素（学習: 2021〜2025年、複勝の同オッズ帯平均との差が±4pt以上・n≥300・年ごとの向きが揃うもの。|差|<10 → ±1点、≥10 → ±2点）。

| 点数 | 要素 |
|---|---|
| +2 | 社台ファーム・追分ファーム・社台コーポレーション白老ファーム生産 / 追切指数レース内3位以内 / 父の新馬複勝回収率90%以上（30走以上） |
| +1 | 1週前追切がレース内1位 / 入厩30日以内 / 厩舎の新馬複勝回収率90%以上（30走以上） / ダートの外枠（7〜8枠） / 激走指数1位 / 外枠（7〜8枠） / 3歳の新馬戦 / 追切指数1位 / 4月生まれ / ダート / 1〜3月のレース |
| −1 | 情報指数レース内下位（下から3頭） / 8〜9月のレース / 騎手の新馬3着内率35%以上（50走以上） / 父の新馬出走が10走未満（新種牡馬など） / 5月以降生まれ |
| −2 | テン指数レース内下位（下から3頭） / 調教量評価A / 仕上指数レース内下位（下から3頭） / 馬主の新馬複勝回収率60%未満（30走以上） / IDMの割に人気（人気順位−IDM順位≤−3） / 追切指数レース内下位（下から3頭） / 生産者の新馬3着内率15%未満（50走以上） / 馬主の新馬3着内率15%未満（30走以上） / 厩舎評価4（弱気） / 調教矢印↓（4,5） |

### 2.1 定義の補足
- すべてレース前に分かる情報だけを使う（今走の T_KYI/T_BAC/T_CYB/T_UKC、今走の日付より前の T_SED）。
- 新馬成績 = 今走の日付より前の新馬戦（T_SED.class='A1'、芝ダ）での出走数・3着内数（異常区分が正常で1〜3着）・複勝払戻の合計。父・生産者は T_UKC（chichi_uma_name・seisansha_name）、厩舎・騎手は T_SED の調教師コード・騎手コード、馬主は T_KYI.umanushi_code で集計する。
- レース内順位（IDM・情報指数・激走指数・テン指数・追切指数・仕上指数・1週前追切指数）は大きい方が上位、同値は同順位。人気順位は基準オッズの小さい順。「下から3頭」は順位が「頭数−2」以上。
- 入厩 = T_KYI.nyukyu_nichi_mae（入厩何日前）。生まれ月・年齢は T_UKC.birthdate。

## 4. 検証

### 4.1 データ
新馬戦 2020〜2026年 1,958レース・25,979頭。2020年は父・厩舎などの累積成績がまだ少ないので学習に使わない。同オッズ帯の平均は新馬戦の中の年別・基準オッズ帯別の平均。

### 4.2 walk-forward（先読みなし、2022〜2026）
| 区分 | 複勝回収率 | 単勝回収率 |
|---|---|---|
| 年内順位 上位10% | 87.5% | 93.3% |

| 下位25〜50% | 68.1% | 65.5% |

- レース内1位の年別の複勝: 74 / 85 / 111 / 90 / 109%（2022年は学習が1年分で弱い）。
- 要素を選ぶしきい値を3〜6ptに変えても、レース内1位の複勝は89〜93%。

### 4.4 新馬戦の主な傾向（下見、2021〜2026、複勝の同オッズ帯平均との差）
追切指数レース内3位以内 +11.5（6年すべてプラス）、1週前追切1位 +11.1、入厩30日以内 +9.1（6年すべて）、社台F・追分・白老生産 +11.4、新馬で回収率の高い厩舎 +8.8・父 +8.9、3歳の新馬戦 +5.7。マイナスは追切・仕上指数がレース内下位 −13（6年すべて）、調教矢印↓ −24.5、調教量評価A −12.2（6年すべて、障害戦とは逆）、厩舎評価4 −19.3、入厩61日以上 −11.6、新種牡馬 −7.9、IDMの割に人気 −11.5、新馬成績の良い騎手（過剰人気）−6.6。兄姉の成績は効果が小さかった（兄姉に勝ち馬あり +2.3）。

## 5. 運用
- 専用の集計テーブル・ETL は無く、出馬表を開いた時点で API が計算する。毎週の「ダウンロード＆DB取込」だけで表示される（父・厩舎などの新馬成績は T_SED から数えるので、前週までの成績取込が前提）。
- 要素は固定。見直すときは `newbie_build.py` → `newbie_wf.py` → `newbie_fixed.py` を再実行し、`src/server.ts` の `computeNewbieIndex()` の要素表を最新年の選定結果に合わせ、突き合わせをやり直す。

## 6. 実装と突き合わせ
- 速度（2026-10-13）: 騎手・厩舎・父などの「その日より前」の成績は、障害戦／新馬戦の成績行をサーバーのメモリに持って数える（`getSedRowsCache()`・`statsBefore()`。T_SED の件数・最終日付が変わったら読み直し、確認は60秒に1回まで。起動時に先読み）。以前は要素ごとに T_SED 全体を集計していて、新馬戦の出馬表が約12秒・障害戦が約3秒かかっていた → 0.03〜0.06秒。
- サーバー: `src/server.ts` の `computeNewbieIndex()`。`/api/races/:raceKey/entries` の各行に `newbie_pts`（点数）・`newbie_items`（内訳）を付ける（新馬戦以外は付けない）。
- 出馬表: `public/entries.html`（列#10、`special` / `specialGrade()`。障害指数と共用）。
- 参照計算: `python/research/newbie_fixed.py <YYYYMMDD>`（その日の新馬戦の全馬の点数を JSON で出力）。12開催日627頭で API と完全一致を確認済み（2026-10-13）。
- 研究用スクリプト（`python/research/`）: `newbie_build.py`（データ構築）→ `newbie_screen.py`（下見）→ `newbie_wf.py`（walk-forward）→ `newbie_robust.py`（同点・しきい値の頑健性）→ `newbie_fixed.py`（固定ルールの点数別・参照計算）。
