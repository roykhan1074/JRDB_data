# 障害指数 仕様書

- 2026-10-12 作成。
- 表示場所: 出馬表（entries.html）列#10「障害」。**障害戦のときだけ表示**（それ以外のレースは幅0で非表示）。

## 1. 目的

障害戦の馬を、障害戦の成績から選んだ要素の点数で評価する。平地とは傾向が大きく違う（初障害・長い休み明け・競走中止明けが大きく割り引かれる、障害成績の良い騎手・厩舎は人気になりすぎる等）ため、障害戦専用に作った。

## 2. 要素と点数（34要素、固定ルール）

`python/research/jump_wf.py` の walk-forward で2026年時点に選ばれた要素（学習: 2021〜2025年、複勝の同オッズ帯平均との差が±4pt以上かつ年ごとの向きが揃うもの。|差|<10 → ±1点、≥10 → ±2点）。

| 点数 | 要素 |
|---|---|
| +2 | 4歳 / 調教量評価A / 見習い騎手 |
| +1 | 前走障害で6着以下 / 激走指数レース内3位以内 / 前走と同じ競馬場（前走障害） / 前走障害で2秒以上負け / 中1〜2週 / IDM下位（レース内で下から3頭） / 調教指数1位 / 総合指数1位 / 障害3〜5戦目 |
| −1 | IDMレース内3位 / 福島 / 中6〜9週 / 騎手の障害3着内率30%以上（50回以上） / 平地で2勝クラス以上を走った / 入厩1走目 / 障害練習1回以上 / 前走障害で1着 / 騎手の障害複勝回収率90%以上（50回以上） / 2走前障害3着内→前走障害4着以下 / 7歳 / 外枠（7〜8枠） / 厩舎の障害3着内率30%以上（30回以上） / 脚質 逃げ / 東京 / 追切指数レース内下位（下から3頭） |

### 2.1 定義の補足
- すべてレース前に分かる情報だけを使う（今走の T_KYI/T_BAC/T_CYB/T_UKC、今走より前の T_SED）。
- 前走・2走前 = その馬の今走より前の T_SED の直近・2番目の行。障害の出走数・平地で走った最高クラス（未勝利=0、1勝=1、2勝=2、3勝=3、OP=4）も今走より前の T_SED から数える。**T_SED は2020年以降しか無い**ため、それ以前に走った経験は数えられない。
- 騎手・厩舎の障害成績 = 今走の日付より前の障害戦の T_SED（騎乗/出走数、3着内数、複勝払戻の合計）。
- 障害重賞 = OP かつ T_BAC.grade が1〜4（1〜3=G1〜G3、4=重賞）。grade=5 は「特別」で重賞ではない。
- レース内順位（IDM・激走指数・総合指数・調教指数・追切指数）は大きい方が上位、同値は同順位。「下から3頭」は順位が「頭数−2」以上。
- 間隔 = T_KYI.rotation（間に入る金曜日の数）。

## 4. 検証

### 4.1 データ
障害戦 2020〜2026年 808レース・9,375頭。2020年は過去成績が数えられず初障害の判定が不正確（前走不明19.6%）なので学習に使わない。同オッズ帯の平均は、障害戦の中で2020〜2026年をまとめた基準オッズ帯別の平均（年別では頭数が少なく不安定なため）。

### 4.2 walk-forward（先読みなし、2022〜2026、毎年その年より前の2021年以降のデータで要素を選び直す）
| 区分 | 複勝回収率 | 単勝回収率 | 年別の複勝（22/23/24/25/26） |
|---|---|---|---|
| 年内順位 上位10% | 102.2% | 104.9% | 94 / 89 / 85 / 121 / 123 |
| 上位10〜25% | 78.5% | 74.9% | |
| 上位25〜50% | 70.6% | 79.0% | |
| 下位25〜50% | 71.7% | 61.4% | |
| 下位25% | 63.3% | 68.4% | |
| 点数のレース内1位（同点は乱数30通りの平均） | 96.7%（幅89.6〜101.1） | 111.8% | 99 / 87 / 76 / 110 / 116 |

- 要素を選ぶしきい値を3〜6ptに変えても、レース内1位の複勝は90〜97%。
- 比較: 障害戦の1番人気 複勝84.6%、IDM1位 81.0%。
- 単勝の100%超は2025〜2026年の高配当頼み。判断材料は複勝。
- walk-forward の点数は年ごとに採用要素の数が違って目盛りがずれる（中央値 2022年+9 → 2024年以降−1）ため、点数の値で年をまたいで比べてはいけない。

### 4.4 障害戦の主な傾向（下見、2021〜2026、複勝の同オッズ帯平均との差）
初障害 −21.6（6年すべてマイナス）、前走で競走中止 −36、中10〜19週 −13.4、重賞 −8.6、逃げ −8.0、外枠 −7.2、平地で2勝クラス以上を走った −6.0、障害成績の良い騎手・厩舎は過剰人気でマイナス。プラスは激走指数レース内3位以内 +9.1、前走と同じ競馬場 +10.0、前走障害で6着以下 +8.5、中1〜2週 +8.5、調教量評価A +11.2、4歳 +8.9。JRDBのテン指数・上がり指数は障害戦では空。

## 5. 運用
- 専用の集計テーブル・ETL は無く、出馬表を開いた時点で API が計算する。毎週の「ダウンロード＆DB取込」だけで表示される（前週の成績取込が前提。騎手・厩舎・馬の過去成績を T_SED から数えるため）。
- 要素は固定。データが増えて見直すときは `jump_build.py` → `jump_wf.py` → `jump_fixed.py` を再実行し、`src/server.ts` の `computeJumpIndex()` の要素表を最新年の選定結果に合わせ、突き合わせをやり直す。

## 6. 実装と突き合わせ
- サーバー: `src/server.ts` の `computeJumpIndex()`。`/api/races/:raceKey/entries` の各行に `jump_pts`（点数）・`jump_items`（内訳）を付ける（障害戦以外は付けない）。
- 出馬表: `public/entries.html`（列#10、`#col-jump`/`#th-jump`、`jumpGrade()`）。
- 参照計算: `python/research/jump_fixed.py <YYYYMMDD>`（その日の障害戦の全馬の点数を JSON で出力）。12開催日157頭で API と完全一致を確認済み（2026-10-12）。
- 2026-10-12、突き合わせの過程で研究側の不具合2件（平地で走った最高クラスの欠損、grade=5 を重賞扱い）を見つけて修正し、検証をやり直した結果が上の数値。
- 研究用スクリプト（`python/research/`）: `jump_build.py`（データ構築）→ `jump_screen.py`（下見）→ `jump_wf.py`（walk-forward）→ `jump_robust.py`（同点・しきい値の頑健性）→ `jump_fixed.py`（固定ルールの点数別・参照計算）。
