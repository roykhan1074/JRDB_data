## 0. 結論（2026-10-04 時点の検証結果）

先読みを除いた検証（毎年「直前の年までの全データ」で集計し直して、その年を採点。§6）で、2024〜2026年の基準オッズ10倍以上の馬を評価した結果：

| EX指数 | 頭数 | 複勝回収率 | 同じオッズ帯の平均 | 差 | 年別の差（2024 / 2025 / 2026） |
|---|---:|---:|---:|---:|---|
| 0未満 | 40,697 | 59.3% | 65.0% | −5.7 | −6.0 / −3.9 / −7.8 |
| 0〜15 | 9,019 | 72.4% | 69.4% | +3.1 | +4.4 / +3.4 / +1.2 |
| 15〜50 | 14,802 | 77.1% | 70.9% | +6.2 | +5.1 / +4.8 / +8.9 |
| 50〜100 | 8,822 | 80.6% | 72.1% | +8.5 | +10.4 / +4.2 / +11.8 |
| 100以上 | 4,490 | 81.4% | 72.7% | +8.7 | +12.2 / +4.2 / +11.3 |

- **複勝**：点数が高いほど、同じオッズ帯の馬より回収率が高い。15以上の帯は3年とも平均を上回る。
- **単勝**：上位の帯は見かけ上平均を上回るが、払戻の大きい上位10件を除くと平均以下に落ちる。**単勝の判断材料としては使わない。**
- **回収率100%超え**：根拠はない。100以上の帯でも複勝81%前後。

## 1. 概要

基準オッズ10倍以上の馬（穴馬）について、JRDBの14ファクターから「**同じオッズ帯の馬と比べて、複勝でどれだけ多く回収できそうか**」を数値化した指数。

利用箇所:
- 注目馬複合シグナル（sc）の指数シグナル・能力フロア（`document/指数/sc_注目馬複合シグナル_仕様書.md`）
- 複勝100シグナルの `scIdx` / `scIdxStrong`
- 出馬表の色分け、分析画面（analyze.html）の帯集計、不利指数（`sql/furi_index.sql`）など

## 2. 対象馬の定義

| 項目 | 定義 |
|------|------|
| 集計の対象 | `T_ANABA_RACE_LOG`（基準オッズ10倍以上・芝ダ・新馬戦除外）のうち、着順が確定し正常に完走した馬（基準オッズ999倍以上は除外） |
| スコアの付与 | 芝ダの**出走全馬**（T_ANABA_SCORE）。結果テーブルには依存しないので、出走前のレースにも付く |
| 意味を持つ範囲 | 基準オッズ10倍以上の馬のみ（10倍未満の馬には使わない） |

## 3. 指数の仕組み

### 3.1 計算式

```
excess（1頭ごと）  = その馬の複勝払戻 − 同じ基準オッズ帯の馬の平均複勝払戻
excess_dev（ファクター値ごと） = AVG(excess) × n / (n + 300)        ← n はそのファクター値の頭数
生スコア raw（1頭ごと）       = 14ファクターの excess_dev の合計（該当値の行が無ければ0）
EX指数                         = raw を旧EX指数の目盛りに換算した値（§3.3）
```

- **オッズ帯**: 10〜15 / 15〜20 / 20〜30 / 30〜50 / 50〜100 / 100倍以上
- **同じオッズ帯との差で測る理由**: 単に人気寄りの馬（=回収率が高くなりやすい）を選んでいるだけ、という見かけの効果を取り除くため
- **複勝で測る理由**: 単勝は数件の大穴で値が大きくぶれるため
- **n/(n+300) を掛ける理由**: 頭数が少ないファクター値の、偶然の偏りを小さくするため（縮小推定）
- **コース×芝ダ×距離帯の細分化はしない**: 細かく分けすぎて過学習の原因になっていたため（旧方式との違い）

### 3.2 フィールド

| フィールド | 内容 |
|---|---|
| `T_ANABA_SCORE.course_score` / `overall_score` | EX指数（**同じ値**。新方式ではコース別の版は無い） |
| `T_ANABA_SCORE.score_*` | 各ファクターの excess_dev（換算前の生の値）。合計は raw と一致し、**EX指数（換算後）とは一致しない** |
| `T_ANABA_FACTOR_AGG.excess_dev` | ファクター値ごとの excess_dev |

### 3.3 目盛りの換算

sc・色分け・分析画面などは EX指数のしきい値（0 / 15 / 50 / 100）を使っている。これらの意味を変えないよう、**旧EX指数とおおよそ同じ割合の馬が各しきい値を超える**ように、生スコアを折れ線で換算する。

| 生スコア raw | EX指数 | 基準オッズ10倍以上の馬のうち、この値以上の割合（2024〜26） |
|---:|---:|---:|
| 4.08 | 0 | 旧 45.5% → 新 43.2% |
| 8.47 | 15 | 旧 34.5% → 新 33.8% |
| 18.27 | 50 | 旧 16.4% → 新 16.6% |
| 31.11 | 100 | 旧 5.5% → 新 5.4% |

両端（4.08未満・31.11超）は、隣の区間の傾きで延長する。換算点は、2024〜26年の検証で「旧EX指数がその値以上だった馬の割合」と同じ割合になる生スコアから決めた。

## 5. テーブル構成と ETL

### 5.1 テーブル

| テーブル | 内容 |
|---|---|
| `T_ANABA_RACE_LOG` | 穴馬（基準オッズ10倍以上）の非正規化ログ。Part2 で追加投入 |
| `T_ANABA_FACTOR_AGG` | ファクター値ごとの集計。新方式では全体集計の行のみ（course_code 等は空）。`excess_dev` 列がスコア計算に使う値。参考用に `baseline/all` 行あり |
| `T_ANABA_SCORE` | 出走全馬の EX指数 |

### 5.2 ETL（`sql/anaba_index.sql`）

```
Part 1: テーブル定義（excess_dev 列の追加を含む）
Part 2: T_ANABA_RACE_LOG に追加投入（差分。ON DUPLICATE KEY UPDATE）
Part 3: 作業表 T_ANABA_EX_WORK を作成 → T_ANABA_FACTOR_AGG_NEW に集計 → 原子的RENAME
Part 4: T_ANABA_SCORE_NEW に全馬を採点 → カバレッジ確認 → 原子的RENAME
```

- 実行時間の目安: 約9分（2026-10-04 実測）
- 実行方法: `download.html` の「EX指数・本命指数を更新する」ボタン、または
  `mysql --default-character-set=utf8mb4 -u root -p racing < sql/anaba_index.sql`
  （`--default-character-set=utf8mb4` を付けないと日本語コメントでエラーになる）
- Part4 の最後に「対象頭数」と「スコアが付いた頭数」を表示する。差が0であることを確認する

### 5.3 既知の注意点

- `T_ANABA_RACE_LOG` は、再投入しても着順・払戻・複合展開フラグしか更新しない。そのため、登録後に JRDB データ（T_KYI）が更新された少数の馬（2026-10-04時点で数十頭）は、**集計にはログの古い値、採点には T_KYI の最新値**が使われる。実害は小さいが、ログの全項目を更新する修正は未対応。
- 本番テーブルは全期間で集計しているため、**本番の値で過去レースの成績を集計すると、未来の結果が混ざって良く見える**。過去成績の検証には §6 の方法を使う。

## 6. 検証方法

- 研究用スクリプト: `python/research/ex_improve_wf.py`（改良案の比較）、`python/research/ex_new_wf_table.py`（新EX指数の walk-forward 採点表 `T_ANABA_SCORE_WF2` を作成）
- 手順: 各年 Y について、Y年より前のデータだけでファクターを集計 → Y年の馬を採点（2022〜2026年）
- 評価: 同じオッズ帯の馬の平均回収率との差を、年ごとに確認。払戻上位10件を除いた値も確認
- 本番SQLとPythonの一致確認（2026-10-04）: 全データで集計・採点して馬ごとに突き合わせ、185,670頭中185,641頭が差0.1以内で一致。残り29頭は §5.3 のログと T_KYI の値の違いによるもの

## 7. 改良案の比較結果（2026-10-04、walk-forward 2022〜2026年）

EX指数の上位5%の馬（約6,600頭）：

| 案 | 複勝回収率 | 同オッズ帯の平均 | 上位10件除外 | 年別の複勝回収率（2022〜2026） |
|---|---:|---:|---:|---|
| 旧方式 | 74.6% | 71.7% | 69.2%（平均以下） | 82 / 66 / 73 / 69 / 85 |
| **新方式（採用）** | **84.3%** | 72.8% | **79.5%** | **92 / 78 / 85 / 80 / 87** |

試した案は7つ（旧方式、調教照合の修正のみ、複勝で集計、＋縮小推定、＋オッズ帯補正、＋コース別なし、その単勝版）。採用した新方式は、5年すべてで平均を上回った。

### 7.1 sc への影響

新EX指数だけを sc に組み込んだ時点では、sc の成績は**良くも悪くもならなかった**（複勝 sc≥4：旧EX指数で+6.1pt → 新EX指数で+4.9pt。年ごとのぶれの範囲内）。EX指数単独の改善がはっきりしているため、ユーザー判断で新方式を採用した。その後、本命指数も新方式にしたところ、sc は複勝 sc≥4 で+5.5pt、sc≥7 で+7.7pt に上がった（`本命指数_仕様書.md` §7.1）。

## 11. 旧方式（2026-10-04 まで）の記録

- 計算: 各ファクター値の**単勝回収率 − ベースライン単勝回収率** の合計。展開系5ファクターは場×芝ダ×距離帯、脚質は場×芝ダ、血統は芝ダ別に細分化した値を優先（course_score）。
- 調教ファクターは、集計が `T_CYB.chokyo_hyoka`（調教評価）、採点が `T_KYI.chokyo_yajirushi`（調教矢印）と、**別の項目どうしを照合する不具合**があった。
- 旧仕様書に載っていた「100以上で単勝374.4%」などの成績は、全期間で集計した値で過去を振り返ったもので、先読みを含んでいた。walk-forward で検証し直すと、上位5%でも複勝74.6%（同オッズ帯の平均71.7%）、払戻上位10件を除くと平均以下だった。
- バックアップ: `T_ANABA_SCORE_BK20261004`・`T_ANABA_FACTOR_AGG_BK20261004`（旧方式の最終データ。不要になったら削除してよい）
