# 方向性④：レース選別による複勝回収率の向上（検証結果）

**分析日：** 2026-09-06
**検証対象：** 「どの馬を買うか」ではなく「**どのレースで勝負すべきか**」を検証する。ベースとなる馬選定は、既にwalk-forward検証済みの `sc≥3（idx/combo/chokyo/goal/joho/ta の複合スコア）× 基準オッズ15〜30倍` 戦略（複勝回収率全体で100.7%、n=3,523、「複勝回収率100%超の統合理論レポート」参照）をそのまま使用し、**レース側の特徴（出走頭数・クラス・グレード）で追加フィルタをかけたときに回収率がどう変化するか**を学習期間(2020/01〜2023/12)・評価期間(2024/01〜2026/08)のwalk-forwardで検証した。

---

## 第0章：結論

1. **レース選別は本物の効果を持つことが確認できた。** 同じ馬選定ロジックでも、**出走頭数10〜13頭の中頭数レースに絞ると学習105.6%→評価118.4%と改善し、14〜18頭の多頭数レースでは学習92.5%→評価97.4%と冴えない**という明確な差が出た。
2. **クラス別ではU字カーブが確認できた：未勝利(A3)とオープン特別(OP)は両期間で100%超を維持したが、2勝クラス相当（classコード"10"）は両期間とも80%台に沈んだ。** 中間クラスは市場参加者の分析精度が最も高く、値付けが効率的である可能性が高い。
3. **「出走頭数10〜13頭 × 未勝利orオープン特別」に絞ると、学習158.6%→評価184.9%という非常に高い回収率を記録した**（n=118/77とやや小さいため継続検証は必要）。より実用的な折衷案として、**「未勝利(A3) × 頭数10〜16頭」**は学習127.1%→評価109.8%、複勝的中率25%台前半で安定しており、サンプル数（n=347/247）とのバランスが良い。

---

## 第1章：出走頭数による効果

| 頭数 | 学習n/回収率/的中率 | 評価n/回収率/的中率 |
|---|---|---|
| 〜9頭（少頭数） | 105 / 181.7% / 19.0% | 75 / 82.3% / 17.3% |
| **10〜13頭（中頭数）** | 504 / 105.6% / 18.3% | 335 / **118.4%** / **23.6%** |
| 14〜18頭（多頭数） | 1,499 / 92.5% / 19.6% | 1,005 / 97.4% / 20.5% |

**評価：** 少頭数（〜9頭）は学習期間で181.7%という数字が出たが評価期間で82.3%まで暴落しており、**n=75〜105と小さいうえに、7頭以下のレースは複勝の的中対象が上位2頭に変わる特殊ルールもあるため、信頼できない**。一方、**中頭数（10〜13頭）は学習・評価の両方で100%を超え、評価期間ではむしろ改善している**。多頭数（14〜18頭）は全体の的中対象の大半（n=1,499/1,005、全体の約6割）を占めるが、回収率は92〜97%と振るわない。**「頭数が多いほど分析が難しく市場が非効率になる」という直感とは逆に、本データでは中頭数レースの方が市場の見落としが残っている**という結果になった。

## 第2章：クラス（条件）による効果

| クラス | 学習n/回収率/的中率 | 評価n/回収率/的中率 | 備考 |
|---|---|---|---|
| **未勝利（A3）** | 427 / **130.3%** / 25.3% | 300 / **104.2%** / 24.7% | 両期間で100%超・的中率も最良水準 |
| 1勝クラス（05） | 689 / 89.3% / 18.0% | 464 / **105.9%** / 20.9% | 評価期間で改善 |
| 2勝クラス（10） | 463 / 80.3% / 16.8% | 273 / 84.7% / 16.1% | **両期間とも唯一100%を大きく下回る** |
| 3勝クラス（16） | 226 / 107.6% / 19.9% | 158 / 95.8% / 19.6% | やや不安定 |
| **オープン特別（OP）** | 303 / **106.6%** / 16.8% | 220 / **113.6%** / 23.6% | 両期間で100%超、評価期間で改善 |

**評価：** **未勝利とオープン特別が両端で強く、真ん中の2勝クラスが最も弱いという「U字カーブ」が確認できた。** 解釈：
- **未勝利戦：** 出走馬の実績が乏しく、市場参加者は血統・馬体・前走の印象といった定性的な情報に頼りがちになる。JRDBの指数（テン指数・上がり指数等の数値評価）は未勝利戦でこそ、定性評価に頼る一般の購入者に対して情報優位を持ちやすいと考えられる。
- **2勝クラス：** 出走馬がある程度勝ち上がってきた「実力が可視化された」馬同士の争いであり、根強いファン層・データ派の購入者の資金が最も集中しやすい階層と考えられる。指数による優位性が市場に織り込まれやすく、エッジが薄い。
- **オープン特別：** 重賞に次ぐ準トップクラスだが、重賞ほどメディア露出がなく、少数の実力馬の中でも市場の評価にばらつきが残りやすい可能性がある。

## 第3章：グレード（格付け）による効果

| 格付け | 学習n/回収率/的中率 | 評価n/回収率/的中率 |
|---|---|---|
| 重賞(G1〜G3) | 167 / 76.3% / 13.8% | 117 / 105.7% / 20.5% |
| その他重賞級(Listed/OP特別等) | 746 / 102.8% / 18.2% | 505 / 98.5% / 20.4% |
| **無格付け（一般条件戦）** | 1,195 / **101.7%** / 20.7% | 793 / **102.9%** / 21.6% |

**評価：** **無格付けの一般条件戦が最も安定して100%前後を維持し、サンプル数も最大。** 重賞（G1〜G3）は学習76.3%→評価105.7%と大きく振れており、n=117〜167と少なく信頼度は低い。**「大きなレースほど荒れて美味しい」という発想は本データでは支持されず、むしろ普段の条件戦の方が地に足のついた優位性を保っている。**

## 第4章：組み合わせ最適化

| 条件 | 学習n/回収率/的中率 | 評価n/回収率/的中率 |
|---|---|---|
| 頭数10〜13頭 × （未勝利 or オープン特別） | 118 / **158.6%** / 21.2% | 77 / **184.9%** / **35.1%** |
| 頭数10〜13頭 × 無格付け | 295 / **106.5%** / 18.3% | 173 / **127.1%** / 23.1% |
| 未勝利のみ（頭数不問、再掲） | 427 / 130.3% / 25.3% | 300 / 104.2% / 24.7% |
| **未勝利 × 頭数10〜16頭** | 347 / **127.1%** / **25.4%** | 247 / **109.8%** / **25.5%** |

**最も推奨する条件：「未勝利(A3) × 頭数10〜16頭」。** 理由：
- 学習・評価の両期間で複勝回収率100%を明確に超えている（127.1%→109.8%）
- 複勝的中率が25.4%→25.5%とほぼ変動せず、**的中率の安定感が非常に高い**（前回までの「オッズ15〜30倍」単体の的中率20%前後よりも高い）
- n=247（評価期間のみ）と、他の絞り込みパターンに比べてサンプル数も確保できている

「頭数10〜13頭×未勝利/OP」は評価期間184.9%と最も高い数字だが、n=77は小さく、継続的な検証が必要な水準。

## 第5章：なぜこれが機能するのか（メタ的な解釈）

第2章・第3章の結果を総合すると、**本データにおける市場の非効率性は「情報が少ない馬（未勝利）」と「情報はあるが関心の薄いレース階層（オープン特別・条件戦）」に偏在しており、「情報も関心も潤沢な階層（2勝クラス・重賞）」には残っていない**、という一貫したストーリーが見える。これは前回の「回収率100%超のための戦術フレームワーク」で整理した(B)市場のゆがみの典型的な発生源（＝分析の手間や関心の非対称性）と合致する。

また、出走頭数については「多頭数＝荒れる」という一般的な直感とは逆に、**中頭数（10〜13頭）が最も優位性を保っている**という結果は、**多頭数レースほど的中対象馬（複勝は上位3着）の絶対数も増えるため、複勝的中率自体は保たれるが、皆が「荒れそうだ」と警戒して手広く流し買いする結果、かえって市場全体が効率化されている**可能性を示唆する（この解釈は本データだけでは確証できないため仮説にとどめる）。

## 第6章：注意事項

1. **サンプルサイズ：** 最良の組み合わせ（頭数10〜13×未勝利/OP）はn=77〜118と小さく、単独では確証度が高いとは言えない。「未勝利×頭数10〜16」（n=247〜347）の方が実用の第一候補として適切。
2. **クラスコードの解釈：** `class`フィールドの値（05/10/16/A1/A3/OP）はJRDBの内部コードであり、本レポートでは05=1勝クラス、10=2勝クラス、16=3勝クラスと推定して解釈した。今後この対応関係を`t_bac`の`race_name`等と突き合わせて確定させることが望ましい。
3. **多重比較：** 頭数3区分×クラス6区分×グレード3区分＝複数の切り口を試しており、その中から良い結果を選んで報告している点に留意する（過去のレポートと同様の限界）。
