# コース別・複勝回収率理論（1番人気除外・2〜3ファクター組み合わせ版）

**分析日：** 2026-09-06
**変更点（前回レポートからの差分）：** ①**1番人気（`kijun_ninki=1`）を分析対象から除外** ②単独ファクターではなく**9ファクターから2つ・3つを掛け合わせた組み合わせ**を総当たりで検証
**検証方法：** 学習期間（2020/01〜2023/12）と評価期間（2024/01〜2026/08）に分割し、**両方の期間で複勝回収率が高水準を維持した組み合わせのみ**を採用（過学習排除の方針は前回と同じ）
**対象コース：** 前回と同じ58コース（場×芝ダ×距離、6.5年でn≥1,800）

---

## 第0章：結論

1. **1番人気を除いた上で2〜3ファクターを組み合わせると、多数のコースで複勝回収率100%超・かつ複勝的中率がベースラインの1.5〜3倍という組み合わせが見つかった。** 165通り（9フラグから2〜3個を選ぶ全組み合わせ）×58コースの総当たりで、**91件が学習・評価の両期間で基準をクリア**した（第2章）。
2. **ユーザー提示の具体例「前半3位以内×IDM印あり×厩舎指数0以上」は、全国的に複勝的中率33〜51%という高い安定感を生むが、回収率が100%を超えて再現したのは中山芝1200mのみだった**（学習91.0%→評価121.1%、的中率41.2%→50.0%）。他のコースでは的中率は高いが回収率は65〜100%のレンジに収まった（第1章）。
3. **大サンプルで特に信頼できる組み合わせ（第3章）：** 東京ダート2100m「ゴール順位3位以内×内枠(1〜4)」、中山芝1600m「テン指数3位以内×調教SP1以上」、東京芝1400m「テン指数3位以内×外枠(5〜8)」など、n=100件以上で学習・評価とも複勝回収率100%超を再現した組み合わせが複数見つかった。
4. **テン指数×上がり指数（ユーザーが最重視する2ファクター）だけの組み合わせも中山芝1200mで有効**（学習123.0%/評価116.3%、的中率46.7%→67.3%）。ただしサンプルはやや小さい（n=60/49）。
5. **注意：165通り×58コース＝9,570通りを検定しているため、一定数は偶然100%を超えて見えているだけの可能性がある（多重比較の問題）。** 第3章はその中でも件数が多く、方向性が競馬理論とも整合する組み合わせを厳選している。

## 第1章：ユーザー提示の具体例の検証

**条件：** テン指数順位3位以内 × IDM印あり（＝IDM上位5位以内、印がついている） × 厩舎指数0以上、1番人気を除く

全58コースで検証したところ、**この組み合わせは複勝的中率を軒並み33〜51%まで押し上げる**（通常のベースラインは16〜20%程度なので、ほぼ2倍以上）。一方、回収率は下表の通り**ほとんどのコースで65〜100%のレンジに収まり、100%を明確に超えて両期間とも再現したのは中山芝1200mのみ**だった。

| コース | 学習n/回収率/的中率 | 評価n/回収率/的中率 |
|---|---|---|
| **中山芝1200m** | 114 / 91.0% / 41.2% | 76 / **121.1%** / **50.0%** |
| 中京ダート1800m | 343 / 84.5% / 41.4% | 190 / **101.4%** / 43.7% |
| 中京芝1600m | 150 / 71.9% / 38.7% | 94 / **101.9%** / 40.4% |
| 京都芝1400m | 52 / 60.6% / 30.8% | 90 / **98.0%** / 42.2% |
| 東京芝1400m | 191 / **102.4%** / 44.0% | 114 / 89.2% / 38.6% |

**評価：** この3ファクターの組み合わせ自体は「複勝的中率を安定して底上げする」効果は全国共通で確認できたが、**回収率100%超えを両期間で確実に再現したのは中山芝1200mだけ**だった。中京ダート1800m・中京芝1600m・京都芝1400mは評価期間で100%近辺まで改善しているため、継続観察の価値はある。

## 第2章：総当たり検証の方法

9ファクターを以下の10種類の二値フラグに変換し（テン指数・上がり指数は「3位以内」で判定）、**C(10,2)+C(10,3)=165通り**の組み合わせについて、コースごとに学習・評価両期間の複勝回収率と複勝的中率を集計した。

| フラグ名 | 条件 |
|---|---|
| ten | テン指数順位 3位以内 |
| agari | 上がり指数順位 3位以内 |
| idm_mark | IDM印あり（IDM上位5位以内） |
| idm_num | IDM数値 55以上 |
| goal | ゴール順位（展開予測） 3位以内 |
| kyusha | 厩舎指数 0以上 |
| chokyo | 調教SP 1以上 |
| waku_in | 枠番 1〜4（内目） |
| waku_out | 枠番 5〜8（外目） |
| jockey | 騎手の全国複勝回収率（学習期間集計）90%以上 |

採用基準：学習期間 n≥50 かつ複勝回収率≥100%、評価期間 n≥25 かつ複勝回収率≥95%。**この基準をクリアした91件**が見つかった（全て2〜3ファクターの組み合わせ）。

## 第6章：注意事項（過信してはいけない理由）

1. **多重比較の問題：** 165通り×58コース＝9,570通りの組み合わせを検定しており、統計的にはこの中の一定数が「本当は効果がないのに偶然両期間で良い数字が出ただけ」の可能性がある。目安として、有意水準を仮に5%とすると9,570通り中で偶然100%超が2回連続する組み合わせが相当数発生してもおかしくない。**第3章（n_評価≥100）を最優先の採用候補とし、第4・5章はサンプルが小さいため「継続観察」の位置づけとすること。**
2. **1番人気を除外した効果について：** 1番人気自体は複勝回収率が比較的高い層（前回分析で単独82%台）であるため、除外することでベースライン自体がやや下がる可能性がある。今回のベースライン値（各表に記載）はいずれも1番人気を除いた母集団の値であり、前回レポートの全体ベースラインとは単純比較できない。
3. **枠番の内外は、コースによって「内枠有利」と「外枠有利」が逆転している**（東京ダート2100m・小倉芝1800m・福島芝1800m・小倉芝1200m・中山芝1200mは内枠、阪神ダート1200m・東京芝1400mは外枠）。これは各コースのコーナー形状・直線長に由来する現実的なコース特性の反映であり、機械的な偶然ではなく理論的な裏付けがあると考えられる。
4. サンプル数が評価期間で100件を下回るもの（第4・5章）は、今後さらに1〜2年分のデータが蓄積された時点で再検証すること。
